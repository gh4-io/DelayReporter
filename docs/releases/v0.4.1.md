# Delay Reporter v0.4.1

A small release on top of v0.4.0: the station's default carriers are fixed, the presets are
reorganised around how a file opens, email can go through Outlook on the web, and Help gains a
reset. It is the first release built, tested and published by GitHub Actions.

## What's new since v0.4.0

- **The default carriers are fixed.** A freshly opened file ticked `S3` instead of `3S` under
  Operators, so AeroLogic was never included. The seven are now `3S`, `CJT`, `CKS`, `CSB`, `DHK`,
  `KII` and `SIA`. Only operators the file holds can be listed, so any of the seven a file lacks is
  now named under the list (*Also wanted, but not in this file: SIA*), and "5 of 11 selected" no
  longer leaves two carriers unexplained.
- **Presets built around how a file opens.** **Standard** is now exactly the opening state: the
  seven carriers ticked and 15 minutes of included delay codes. **All** is what Standard used to
  be, every operator at 15 minutes, and **MX only** is Standard narrowed to MX delays. Every coded
  delay and Over an hour are unchanged.
- **Send with Outlook on the web.** Settings > Email > Send with offers Outlook on the web for a
  work or school account and Outlook.com for a personal one, beside the default mail app. The
  browser opens a new message with the recipients and subject filled in, the formatted table is
  on the clipboard to paste with Ctrl+V, and the workbook is saved and shown in its folder to drag
  in, since Outlook's compose link can carry neither. Nothing is sent from the application.
- **Help > Reset.** After asking, it moves `%APPDATA%\Delay Reporter` (settings, saved presets and
  the mapping CSVs, edits included) to the Recycle Bin and restarts Delay Reporter as first
  installed. A reset by mistake can be restored from the Recycle Bin.

## Running it

Same as before: download `DelayReporter.exe` and run it. No installer, no runtime to install, no
administrator rights. `DelayReporter.exe.sha256` beside it holds the executable's SHA-256 hash.
Only the station and the minimum delay with its basis carry over between sessions; the filters
start from Standard with every file.

## Validation

GitHub Actions built the executable on Windows with no warnings, and the core regression checks
(including new ones for the presets, the Outlook on the web link and the clipboard format) and the
repository checks all pass against it. This release publishes that same tested executable. The
window itself (the Operators note, the new presets, the Outlook on the web flow and Reset) should
still be looked at against a real movement sheet.
